# Dane do ćwiczenia „Spróbuj sam” (wykład „Nowy Świat”, WPiA UAM, 2.10.2026)

Dwa małe wyciągi z bazy **UN Human Rights Voting Records** (HRC Voting): https://lszoszk.github.io/hrc-voting/ — pełna, sprawdzona baza jest tam.

| plik | co zawiera |
|---|---|
| `glosowania_na_rok.csv` | liczba rezolucji przyjętych w głosowaniu imiennym, na rok: Komisja Praw Człowieka (`CHR`, 1946–2006) i Rada Praw Człowieka (`HRC`, od 2006); 1947–2026, razem 1 248 |
| `zgodnosc_z_usa_i_chinami.csv` | 110 państw Rady Praw Człowieka 2006–2026: jak często (%) głosowały tak samo jak USA (`agree_with_USA_pct`) i jak Chiny (`agree_with_CHN_pct`), liczba wspólnych głosowań (`shared_votes`), grupa regionalna ONZ (`un_group`); `most_active` = 1 dla 28 najaktywniejszych państw |

Zakres: tylko rezolucje (bez poprawek i decyzji). Źródło: OHCHR Search Library — kolekcja Voting (searchlibrary.ohchr.org). Stan: 17.09.2026.
